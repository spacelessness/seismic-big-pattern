# 中国官方长时段中小地震目录：来源与申请清单

核查日期：2026-10-09。需求：**中国及周边、尽可能长的时间、所有公开可获得震级，不预设完备性**。区域工作框采用 70–140°E、0–60°N（不是行政国界，含大量邻国和海域）。

## 1. 官方优先目录（尚未获得全量导出）

### 中国地震台网（CSN）1970—2017 目录

入口：<https://data.earthquake.cn/datashare/report.shtml?PAGEID=earthquake_csn>

官方介绍时间范围为 1970-01-01 至 2017-08-31，163,922 个事件，来自国家测震台网、区域有人职守台站和模拟台站共 88 台的测定；页面明确**国际时 GMT**。列中同时存在 `Ms, Ms7, mL, mb, mB`（见上入口）。

注意：163,922 是官方介绍里的全库规模，**不是本仓库已下载条数**，也不是筛选后的中国区域条数。页面默认展示的 20 条/某月份总数不能冒充整个目录。多震级列中的 0.0 可能有特定缺测约定，必须查字段说明，不能直接当作零级地震，也不能全列无条件取最大值。

### 中国地震台网统一编目正式目录，2009 年起

入口：<https://data.earthquake.cn/datashare/report.shtml?PAGEID=earthquake_zhengshi>

官方说明从 2009-01-01 开始统一国家和区域台网编目；页面列明**北京时间**、经纬度、深度 km、震级类型、震级、震中位置和事件类型（见上入口）。

这才是希望取得全国中小震正式观测目录时的主要目标。公开速报（`earthquake_subao`、新闻速报页）并不是它的等价替代。本次验证了公开页可读，**未取得全量目录导出**，应在官方页面按当前实际登录/申请/共享条款操作。不绕过身份校验或获取未授权的后台接口。

### 中国历史地震目录

入口：<https://data.earthquake.cn/datashare/report.shtml?PAGEID=datasourcelist&dt=8a85efd754e7d6910154e7d691810000>

介绍覆盖公元前 1831 年至 1969 年的破坏性地震 M≥4；该页标题信息写 5,136 条、摘要写 5,163 条，数字本身不一致，应向发布方核对，不能当作本仓库条数（见上入口）。

它可以扩展历史时段，**不是历史小震全记录**。原仓库 EQT 已包含历史记录，后续不能简单追加造成重复。

## 3. 可直接提交给数据平台的需求文本

> 用途：地震大形势与区域地震活动性研究，非商业导航/工程设防产品。\
> 空间：东经 70—140°、北纬 0—60°；若平台按行政/台网分区提供，请保留分区条件。\
> 时间：CSN 从 1970-01-01 到其终止时间；统一编目从 2009-01-01 到最新可共享正式版本。历史目录另取，不与仪器目录静默合并。\
> 震级：全部可共享记录，不设最低震级；需保留未定震级及所有原始震级类型。\
> 必要字段：事件编号、发震时间及明确时区、经纬度及坐标基准、深度及单位、每类震级及缺测约定、事件类型、震中地名、定位/震级机构、质量标志、误差、更新时间。\
> 还需：数据字典、编目规范/变更、台网监测能力变化说明、建议引用、允许的研究用途、是否允许向本公开仓库再分发原数据或派生数据。\
> 格式：UTF-8 CSV/TSV/TXT 优先；只要目录参数，不需要连续波形。

不要在仓库或聊天中提交登录密码、身份证明、个人订单或访问令牌。

## 4. 合并前必须处理

1. CSN GMT 与统一编目北京时间（UTC+8）不能直接拼接。时区未明的研究目录先隔离，不能擅自加 `Z`。
2. 多来源事件匹配需结合时间、空间、震级类型和原 ID；**不跨来源自动去重**，也不把重新定位解当作新地震。
3. 保留负震级、零级和缺失值之间的区别；检查不同目录中 `0`、`-1` 等是否为缺测码。
4. 历史未知月/日、负年份、估计时间应保留，不制造精确 UTC 时间戳。
5. 单一台网、AI 目录和国家台网的检出能力差异很大。年度数量突然增多可能是台网/算法变化，不能直接判断区域活动增强。
